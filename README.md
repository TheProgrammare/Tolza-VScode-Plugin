A complete Visual Studio Code extension that brings first-class support for the **Velox** programming language.

> For Velox project, see [here](https://github.com/TheProgrammare/Velox)

## Features

The **Velox** extension provides a modern, seamless, and ergonomic development experience by integrating the core language tooling directly into Visual Studio Code.

### Syntax Highlighting

* Full syntax highlighting for the Velox language.
* Support for keywords, types, comments, strings, numbers, operators, and other language constructs.
* Compatible with all Visual Studio Code themes.

### Syntax Analysis

Powered by the official Velox parser, the extension provides:

* Real-time syntax error detection.
* Accurate diagnostics and error reporting.
* Immediate feedback while you write code.

### Integrated Compilation

Compile your Velox projects directly from Visual Studio Code.

The extension integrates the Velox compiler into your workflow, allowing you to build your projects without leaving the editor.

## Designed for Productivity

The goal of this extension is to provide a native and intuitive development experience for the **Velox** programming language within Visual Studio Code.

By combining syntax highlighting, syntax analysis, and integrated compilation, the extension enables a smooth and efficient workflow from writing code to building your applications.

## Why Velox for VS Code?

* Complete syntax highlighting.
* Built-in syntax analysis.
* Integrated compilation.
* Fast, ergonomic, and seamless workflow.
* Native Visual Studio Code integration.


Develop Velox applications with confidence using an extension designed to make the language feel like a first-class citizen in Visual Studio Code.
